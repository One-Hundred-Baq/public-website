# Use of Funds — COP $1,000,000 (initial / launch capital)

**These are estimated allocations, not vendor quotes.** Real costs (legal filing fees, hosting) must be confirmed before spending — this document sets intent and rough proportion, not a signed budget.

| Allocation | Approx. share | What it covers | Why it's needed |
|---|---|---|---|
| Persistent hosting for the AI sales agent | ~35% | A small always-on server or managed hosting so the WhatsApp/Telegram bot runs continuously instead of only during a working session | This has been an open gap since before Phase 1 — GitHub Pages can't run it, and it's the one piece of the proven engine that isn't running unattended today |
| Domain + basic legal/trademark search | ~30% | Registering a real domain for One Hundred, and a preliminary trademark availability search (not full registration — see `Launch/TrademarkChecklist.md`) | The company currently has no domain and no trademark clearance of any kind |
| LLM API costs for the live agent | ~15% | Gemini API usage for the public site's AI agent once fully active | The agent runs on a rule-based fallback whenever the live model is unavailable; real usage at any volume needs paid API credits |
| Buffer for first real go-to-market push (second client) | ~20% | Whatever it costs to find and close one more real, named client using the existing engine | Directly tests whether the "reusable engine" claim holds for a second business, not just Osman Vergara |

## What this explicitly does NOT include

- Salaries or founder compensation.
- Paid advertising at any meaningful scale.
- Full trademark registration (see `Launch/TrademarkChecklist.md` — that alone may cost more than this entire raise, depending on jurisdiction and class count, and needs its own decision once real quotes exist).
- Legal entity formation costs, unless confirmed to fit after the above.

## Why COP $1,000,000 specifically

It's sized to validate and launch — covering the one real operational gap (persistent hosting) and the minimum legal/domain groundwork — not to scale an already-proven business. See `02-CapitalDeck.md` slide 7.
